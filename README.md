# Hello Button JavaFX

A beginner JavaFX project built with Java and Maven to learn the fundamentals of graphical user interface (GUI) development.

## Features

- Displays a simple JavaFX window
- Includes a clickable button
- Updates a label when the button is clicked
- Uses FXML to define the user interface

## Technologies Used

- Java
- JavaFX
- FXML
- Maven

## How to Run

1. Install a compatible JDK and Maven.
2. Clone this repository.
3. Open a terminal in the project directory (the folder containing `pom.xml`).
4. Run:

   ```bash
   mvn javafx:run
   ```

## What I Learned

- How to structure a JavaFX application
- How FXML connects the interface to a controller
- How button events call Java methods
- How Maven manages project dependencies
